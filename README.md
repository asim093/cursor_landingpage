Cursor Landing Page Clone 

A frontend landing page clone inspired by Cursor built as part of my learning journey while following Chai aur Code – Cohort 2026.

This project focuses on clean UI, layout structure, reusable CSS variables, and modern hover interactions, closely matching the look and feel of the original Cursor website.

Design System
Color Palette (CSS Variables)
:root {
  --background-color: #14120b;
  --secondary-background-color: #1b1913;
  --text-color: #ffffff;
  --secondary-text-color: #ff4704;
  --primary-text-color: #b9b9b9;
}


Primary background: Dark charcoal (#14120b)

Secondary background: Soft dark (#1b1913)

Primary text: White

Accent color: Cursor orange (#ff4704)

Muted text: Light gray

Fonts

Primary font: sans-serif

Buttons & highlights: Arial, Helvetica, sans-serif

(Font stack kept simple to focus on layout and design fundamentals.)

HTML5

CSS Variables
